# Hive

Releases and issue tracking for Hive, a local-first macOS app for managing OpenCode sessions.

## Download

Download the latest signed and notarized `.dmg` from [Releases](https://github.com/Ajanth/hive-public/releases/latest).

Hive checks the signed Sparkle feed for automatic updates. Every update is verified with Hive's embedded EdDSA public key before installation.

## License

Hive is licensed under the [MIT License](LICENSE). The distributed app includes the same license text.

Day-to-day development happens in a private repository. This public repository hosts releases and user feedback.

## Security & Privacy

Hive keeps session data on your Mac and does not include telemetry, analytics, or remote logging. Network access is limited to documented, user-visible features such as signed update checks and actions the user explicitly initiates.

To report a security issue privately, email `ajanth2newearth@gmail.com`.
